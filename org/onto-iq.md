# Onto-IQ — topic family

Use this org for **AI** courses. Same folder tree as DataFabric-Academy; only topics change.

## Typical topics
- n8n / workflow automation
- Copilot Studio
- Multi-agent workshops (Claude Code, hybrid agents)
- Power Automate (desktop / AI)
- Power Platform AI Builder

## Content tips
- PAD-style units map cleanly: `LESSON.md` + `LAB.md` with shared `NN-slug`.
- Multi-agent courses may keep a separate workshop/app repo; this course repo stays lessons + labs + other.
- Thai case-study names are fine under `other/` when needed; keep `lessons/` and `labs/` slugs ASCII.
