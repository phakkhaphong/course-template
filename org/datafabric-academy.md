# DataFabric-Academy — topic family

Use this org for **data platform** courses. Same folder tree as Onto-IQ; only topics change.

## Typical topics
- Power BI (modeling, DAX, Power Query, reports)
- Microsoft Fabric (Lakehouse, Warehouse, pipelines, semantic models, data science)
- SQL Server (query, administration, performance, backup/restore, scripting)

## Content tips
- Prefer bilingual README sections (Thai headers + English commands).
- Labs often need `starter/` SQL/notebooks and `other/datasets/`.
- Instructor decks usually live under `other/slides/` (or a pointer README if decks stay local).
