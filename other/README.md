# Other / เอกสารและไฟล์ประกอบ

Supporting materials that are not lessons or exercises. Keep teaching content in `lessons/` and `exercises/`; put everything else here.

| Folder | Purpose |
|--------|---------|
| [assets/](assets/) | Images and diagrams |
| [datasets/](datasets/) | Sample data used by lessons/exercises |
| [slides/](slides/) | Deck files or a pointer to an external deck |
| [docs/](docs/) | JD, instructor notes, glossary |
| [reference/](reference/) | Cheat sheets, failure modes, Learn maps |
| [scripts/](scripts/) | Helper scripts and structure check |

Thai filenames are allowed here when needed. Do not add new top-level sibling folders for supporting content — extend this tree instead.
